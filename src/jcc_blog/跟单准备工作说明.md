# Hyperliquid 跟单前的准备工作说明

## 1. 先说明一下

如果你想在 Hyperliquid 上使用跟单功能，最重要的不是“程序怎么写”，而是先把账户、资金、权限和风险控制准备好。Hyperliquid 的跟单，本质上是让系统替你在其交易环境中执行开仓、加仓、减仓、平仓等动作，因此必须先确认你的资金已经进入可交易环境，并且授权范围足够安全。

## 2. 准备工作总览

普通用户在 Hyperliquid 上开始跟单，大致需要完成以下准备：

1. 创建并确认可用的钱包账户
2. 准备基础资产，例如 USDC
3. 为后续交易准备足够的燃料或手续费
4. 将 USDC 充值到 Hyperliquid 的合约交易环境中
5. 生成并配置 API Key 或访问凭证
6. 设置跟单比例、启动/暂停规则和人工操作逻辑
7. 先以小资金进行测试，再正式启用

## 3. 账户准备

### 3.1 准备 Hyperliquid 可用钱包

- 你需要先拥有一个可用的钱包地址。
- 这个钱包要能接收 USDC，并且能与 Hyperliquid 的交易环境配合使用。
- 账户状态要确认正常，具备后续充值和交易能力。

### 3.2 确认账户可交易状态

- 确认你的账户已经具备正常交易能力。
- 确认没有账户限制、权限限制或资金冻结问题。
- 如果你准备让第三方程序或跟单工具操作，最好先确认账户权限是否满足要求。

## 4. 资金准备

### 4.1 充值 USDC

- 先把 USDC 充值到 Hyperliquid 相关账户中。
- 这是跟单最基础的资金准备步骤。
- 没有足够的基础资产，后续即使配置了跟单规则，也无法真正执行交易。

### 4.2 充值燃料或手续费

- 在 Hyperliquid 这类链上交易环境中，交易通常需要支付一定的费用或燃料。
- 如果没有足够的费用，交易动作可能无法成功。
- 这一步是很多用户容易忽略的准备项。

### 4.3 将 USDC 转入合约交易环境

- 充值完成后，还需要把资金转入 Hyperliquid 的合约交易环境中。
- 只有资金真正进入可交易环境后，才能进行开仓、加仓、平仓等操作。
- 这一步是“有资金但还不能交易”的关键过渡点。

## 5. 权限与凭证准备

### 5.1 生成 API Key

- 如果你准备让跟单程序或第三方工具代你执行交易，通常需要先生成 API Key。
- 这个凭证的作用是让程序能够访问账户的交易接口。

### 5.2 明确权限范围

- Hyperliquid 的 API Key 主要用于交易执行权限，通常不具备资产转移能力。
- 也就是说，生成后它可以用于下单、撤单、查询等交易相关操作，但通常不能用于提币或转移资产。
- 对跟单场景来说，这意味着风险更集中在“误交易、超额持仓、连续下单”这类问题，而不是资产被直接转走。
- 因此，用户在使用时应把重点放在“限制交易范围”和“设置风控规则”，而不是把资产控制权交给程序。

### 5.3 注意安全

- API Key 不要随意泄露给不可信的平台或脚本。
- 最好将其存放在安全环境中，并尽量只开放最小必要权限。
- 对于跟单程序，建议优先采用“只允许下单、撤单、查询”的权限模型。

## 6. 跟单规则准备

### 6.1 选择跟单对象

- 先确定你要跟随谁。
- 可以是某个账户、某个策略、某个信号源，或者某个已知的交易行为。

### 6.2 设置跟单比例

- 如果你手上的资金小于跟单对象的资金规模，需要设置比例控制。
- 例如跟单对象的资金规模为 10000，而你只有 1000，那么比例系数通常不能超过 0.1。
- 这样可以避免你的仓位放大过多，导致不成比例的风险暴露。
- 另外需要注意，比例系数过小时，按比例换算后的订单金额可能低于平台允许的最小挂单额度。
- 在这种情况下，系统可能无法成功挂单，导致某些订单无法被跟踪或复刻。
- 因此，跟单比例设置时，不仅要考虑资金比例，还要考虑平台的最小下单金额和最小挂单限制。

### 6.3 设置启动和暂停规则

- 需要明确：
  - 什么时候启动跟单
  - 什么时候暂停跟单
  - 什么时候人工介入
- 这一步很重要，因为跟单程序并不是永远都应该自动执行。

### 6.4 设置手工操作逻辑

- 用户需要能手动执行：
  - 启动跟单
  - 暂停跟单
  - 关闭跟单
  - 手动平仓
  - 临时调小跟单比例

## 7. 风控准备

### 7.1 设定最大仓位

- 不要让系统因为跟单比例过大而无限放大仓位。
- 你的仓位上限应该与资金规模和风险承受能力相匹配。

### 7.2 设定最大亏损

- 需要设置单笔、单日或总账户的亏损上限。
- 这样即使跟单对象出现异常，也能在损失扩大前停下来。

### 7.3 设定最大比例

- 不要让程序只因为跟单对象规模很大，就让你跟得过满。
- 资金差异必须被纳入判断。

### 7.4 设定止损规则

- 如果跟单对象出现异常、反向操作或明显失控，系统要能快速暂停或减少暴露。

## 8. 测试与上线

### 8.1 先小额测试

- 不建议一开始就大额使用。
- 先用小规模资金测试规则是否正确。
- 重点检查是否真的按预期执行下单、撤单、暂停和平仓。

### 8.2 观察执行结果

- 在测试阶段重点观察：
  - 是否正确跟随交易方向
  - 是否按比例控制资金
  - 是否在暂停时立刻停止动作
  - 是否能正确处理人工干预

### 8.3 逐步放大

- 当测试通过后，再根据你的风险承受能力逐步增加规模。
- 不建议一开始就把大额资金直接交给自动化逻辑。

## 9. 注意事项

- Hyperliquid 上的跟单不是自动稳赚，仍然存在交易风险。
- 资金管理和风控比“功能是否能实现”更重要。
- 任何自动化交易都需要有紧急停机机制。
- 不要把高权限凭证交给不可信的平台或脚本。
- 对于普通用户来说，最稳妥的做法是先只授予必要的交易权限，而不是一开始就开放全部权限。

## 10. 总结

如果你想在 Hyperliquid 上开始跟单，核心准备工作可以概括为：

1. 准备可用钱包和账户
2. 充值 USDC
3. 为交易准备燃料或手续费
4. 将 USDC 转入 Hyperliquid 的合约交易环境
5. 生成并配置 API Key 或访问凭证
6. 设置跟单比例和风控规则
7. 配置启动、暂停和人工干预逻辑
8. 先小额测试，再正式使用
